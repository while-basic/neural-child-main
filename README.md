# Neural Child Development System

A sophisticated AI system that simulates child-like learning and emotional development through neural networks and natural language processing.

## Features

- Emotional Memory System
- Time Awareness
- Vocabulary Learning
- Developmental Stages
- Dream Generation
- Self-Awareness
- Emotional Response System

## Components

1. **Digital Child**: Core class representing the AI child with developmental stages and metrics
2. **Neural Brain**: Neural network architecture handling language processing and emotional responses
3. **Chat Interface**: Interactive communication system with emotional memory and time awareness
4. **Obsidian Integration**: Knowledge management and vocabulary learning system

## Technical Details

- Built with PyTorch and Transformers
- Uses DistilBERT for language understanding
- ChromaDB for conversation and memory storage
- Obsidian for knowledge management
- Custom neural networks for emotional processing

## Setup

1. Install dependencies:
```bash
pip install -r requirements.txt
```

2. Run the chat interface:
```bash
python test_chat.py
```

## Usage

Available commands:
- `vocab`: Display vocabulary statistics
- `emotions`: Show current emotional state
- `time`: Display time awareness information
- `dream`: Generate a dream based on recent memories
- `exit`: End the conversation
